# Data Governance

Types governing the sensitivity, licensing, retention, and consent aspects of datasets.

* [DataGovernance](DataGovernance.md) - Governance metadata bundle for a dataset.
* [RetentionPolicy](RetentionPolicy.md) - Data retention policy (duration, basis, purposes).
* [ConsentSpec](ConsentSpec.md) - Data subject consent requirements and conditions.
* [FieldSpec](FieldSpec.md) - Schema field descriptor for tabular data and model I/O.
