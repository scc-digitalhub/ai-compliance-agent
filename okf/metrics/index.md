# Metrics

Types for defining, composing, and recording measurements that underpin compliance objectives.

* [Metric](Metric.md) - Quantitative or qualitative measure of a defined notion.
* [MetricComposition](MetricComposition.md) - Aggregation specification for a composite metric.
* [MetricResult](MetricResult.md) - Observed value of a single metric within a report.
* [ConfidenceInterval](ConfidenceInterval.md) - Statistical confidence interval for a metric result.
* [UnitOfMeasure](UnitOfMeasure.md) - Physical unit of measurement for a metric value.
* [ValueRange](ValueRange.md) - Valid value domain for a metric.
