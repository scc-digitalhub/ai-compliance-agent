# Compliance Status & Documentation

Types tracking the compliance verdict, findings, mitigations, and documentation
for any first-class entity (project, data, model, model service).

* [ComplianceSpec](../specs/ComplianceSpec.md) - Top-level compliance extension attached to any entity.
* [ComplianceStatus](ComplianceStatus.md) - Assessed compliance status at a point in time.
* [ComplianceFinding](ComplianceFinding.md) - A non-conformance finding from a compliance assessment.
* [MitigationAction](MitigationAction.md) - Action engaged to resolve a compliance objective violation.
* [ComplianceDocumentation](ComplianceDocumentation.md) - Structured documentation for an entity's compliance dimension.
* [DocumentSection](DocumentSection.md) - A titled section within a documentation artifact.
