# Compliance Objectives

Types expressing what a compliant entity must satisfy: a metric bound to an
acceptance condition.

* [ComplianceObjective](ComplianceObjective.md) - Normative constraint binding a Metric to a target value or region.
* [ObjectiveCondition](ObjectiveCondition.md) - Condition envelope (threshold, range, categorical, statistical, composite).
