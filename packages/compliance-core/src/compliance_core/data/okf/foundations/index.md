# Foundations

Core identity, reference, and provenance types reused throughout the framework.

* [BaseComplianceObject](BaseComplianceObject.md) - Lightweight identity base inherited by all compliance model objects.
* [ActorRef](ActorRef.md) - Reference to a human user, service account, or automated agent.
* [EntityRef](EntityRef.md) - Opaque cross-entity reference key.
* [Lineage](Lineage.md) - DAG of derivation relationships for an artifact.
* [DomainDescriptor](DomainDescriptor.md) - Domain and use-case classification.
* [RegulatoryRef](RegulatoryRef.md) - Normative reference to a regulatory framework article or section.
