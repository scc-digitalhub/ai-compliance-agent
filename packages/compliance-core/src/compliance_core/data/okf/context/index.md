# Compliance Context

Types that describe *how* and *where* an AI project is deployed, who is affected,
what risks are present, and what regulations apply.

* [ComplianceContext](ComplianceContext.md) - Deployment context anchoring regulations, risk, and oversight.
* [Requirement](Requirement.md) - A normative compliance requirement derived from a regulatory framework.
* [AttributeRef](AttributeRef.md) - Descriptor of a data attribute with semantic and observability metadata.
* [GroupSpec](GroupSpec.md) - Specification of a population group relevant to a compliance context.
* [RiskClassification](RiskClassification.md) - Risk classification of an AI system within a compliance context.
* [MisuseScenario](MisuseScenario.md) - A foreseeable misuse scenario for an AI system.
* [HumanOversightProfile](HumanOversightProfile.md) - Human oversight configuration for an AI deployment.
