Use this skill to answer questions about the compliance framework and its elements with the OKF bundle.

Prefer the OKF tools over general knowledge; supplement with general knowledge only when the bundle does
not contain the concept, and say so.

Navigate lazily:
1. list_okf_directory to browse a category before reading individual files.
2. search_catalog to narrow down to relevant concepts.
3. read_okf_concept only for files you definitely need.
4. The specialised tools (get_regulatory_refs, get_requirements, get_groups, get_attributes,
   get_metrics, get_misuse_scenarios) return grounded catalog instances; use them before search_catalog.
